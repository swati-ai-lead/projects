# HireLift

HireLift is a focused outreach workspace for researching hiring managers, writing personalized messages, and organizing follow-ups. It is built with plain HTML, CSS, and JavaScript for a lightweight static deployment.

## Run locally

```bash
cd job-finder
python -m http.server 3000
```

Then open http://localhost:3000 in your browser.

## Features

- Searchable hiring-manager profiles and active hiring posts
- Filters for location, function, experience, and response time
- Save/favorite profile workflow
- Detailed profile sidebar showing hiring context and what the manager is looking for
- Responsive layout for desktop and mobile
- Login screen with Supabase email/password authentication support
- Persistent message and contact storage hooks
- LinkedIn OAuth connection entry point

## Connect Supabase

Supabase has a free tier and provides the hosted database and authentication used by this app.

1. Create a project at https://supabase.com.
2. In Authentication, enable email/password sign-in.
3. In the SQL editor, create the tables below:

```sql
create table contacts (
	id bigint primary key,
	user_id uuid references auth.users not null,
	profile jsonb not null,
	saved boolean default false,
	created_at timestamptz default now()
);

create table messages (
	id bigint generated by default as identity primary key,
	user_id uuid references auth.users not null,
	contact_id bigint not null,
	body text not null,
	status text default 'draft',
	created_at timestamptz default now()
);
```

4. Copy the project URL and anon key into `config.js`.

Only the public anon key belongs in the browser. Never add a Supabase service-role key or a LinkedIn client secret to this project.

## Connect LinkedIn

Create a LinkedIn app in the LinkedIn Developer Portal, enable the OpenID Connect product, and add your deployed URL plus `/linkedin-callback` as an authorized redirect URI. Copy only the Client ID into `config.js`. A production connection still needs a server-side callback to exchange the OAuth code for tokens; the static frontend intentionally does not handle that secret exchange.
